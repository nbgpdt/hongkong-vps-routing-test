## 为什么要做香港 VPS 路由测试：延迟低不等于线路好

先说一个最容易被忽略的常识：**Ping 值低 ≠ 路由好**。

你 ping 一个香港 IP，看到 30ms 的延迟，心想"哇这线路真香"，于是下单。但你 ping 的只是"去程"的一小段，数据从你的电脑出发到香港服务器这一段确实快，可数据从香港服务器返回到你电脑这一段——也就是**回程路由**——可能绕了半个地球。

香港 VPS 的网络质量，主要由两段决定：

- **去程路由**：你 → 香港。这段通常走得都不差，因为大多数商家在香港本地都有 BGP 接入。
- **回程路由**：香港 → 你。这段才是真正的分水岭。便宜线路走的是普通 163 骨干，晚高峰堵到怀疑人生；精品线路走 CN2 GIA、9929、CMIN2，晚上照样能跑满带宽。

所以老玩家挑香港 VPS，第一件事不是看 ping 值，而是测回程路由。如果你看到一个商家只晒 ping 值、只晒去程、不给你 Looking Glass、不让你测回程，那基本可以判断——回程八成有猫腻。

> 一句话总结：去程是面子，回程是里子。买香港 VPS，里子比面子重要十倍。

## 三大运营商的线路黑话：163、CN2 GIA、CMIN2、9929 到底是什么

要做香港 VPS 路由测试，得先看懂测试结果里那一串串的数字和 AS 号代表什么。下面用大白话给你拆一遍。

### 中国电信的三档线路

- **AS4134（163 骨干）**：电信最基础的老线路，公网骨干，谁都能用，便宜。晚高峰丢包率高、延迟抖动大，是"普通直连"的典型代表。路由节点里看到 `202.97.x.x` 就是它。
- **AS4809（CN2 GT）**：CN2 的入门款，比 163 好一些，去程或回程部分走 CN2，部分仍走 163。属于"半精品"。
- **AS4809（CN2 GIA）**：CN2 的旗舰，全程走 `59.43.x.x` 节点，不掺 163。延迟低、丢包少、晚高峰稳，是电信用户梦寐以求的线路。**真正的"三网精品回程"必然包含 CN2 GIA。**

### 中国联通的两档线路

- **AS4837（普通联通）**：联通的基础骨干，类似电信 163 的定位。
- **AS9929（联通精品）**：联通的 CN2 等价物，质量明显高于 4837，晚高峰表现稳。**9929 是判断联通回程是否精品的关键标志。**

### 中国移动的两档线路

- **AS58453（CMI 普通）**：移动的国际出口，普通质量。
- **AS5880（CMIN2）**：移动的精品线路，对标电信 CN2 GIA。**CMIN2 是移动回程的最高规格。**

把这些记住，你拿到一份回程路由测试结果，扫一眼 AS 号就知道这商家给你的是良心货还是注水货。比如路由里全程看到 `59.43.x.x`（CN2 GIA）、`218.x.x.x` 或 `219.x.x.x` 走 9929、移动段走 CMIN2——恭喜你，这是真三网精品回程。反之，如果回程大段都是 `202.97.x.x`，那商家宣传的"精品线路"基本可以打五折听。

## 香港 VPS 路由测试工具箱：购买前 vs 购买后分别用什么

测路由的工具分两类：**还没买的时候**用商家提供的测试资源，**买完之后**用自己的服务器跑脚本。两套打法不一样，下面分开说。

### 购买前：靠测试 IP 和 Looking Glass 先验货

正规商家官网都会提供两样东西：

- **测试 IP**：一个公开的 IP 地址，你 ping 它、traceroute 它，能大致判断去程质量。
- **Looking Glass（LG）**：一个网页工具，你在上面输入自己的家庭 IP，让商家的服务器主动 traceroute 到你这里——这就模拟了**回程路由**。这是购买前判断回程质量最权威的方法。

用 Looking Glass 的正确姿势：找一个像 [ipw.cn](https://ipw.cn)、[itdog.cn](https://itdog.cn) 这样的国内多节点测试平台，从北京、上海、广州电信 / 联通 / 移动分别 ping 商家给的测试 IP，再去商家 Looking Glass 页面反向 traceroute 到这几个城市的测试节点 IP，对比一下路径。

> 提醒一句：有些商家只在宣传页贴测试 IP，但 Looking Glass 页面要么藏得很深、要么干脆没有。这种情况要么主动问客服要，要么直接 pass。GoMami 这种把 Looking Glass 和测试 IP 都公开挂在官网的，至少说明人家对自家线路有底气。

### 购买后：SSH 登录跑脚本，拿到一手机器实测数据

买完之后，真正的香港 VPS 路由测试才算开始。主流脚本有三个，建议都跑一遍交叉验证。

**1. BestTrace.sh —— 最经典的三网回程一键脚本**

bash
wget -qO- git.io/autobesttrace | bash


跑完它会自动 traceroute 到中国电信、联通、移动、教育网的多个节点，输出每一跳的 IP、延迟、归属 AS 号。看回程路由最直观的工具，没有之一。看到路径里全程 `59.43` 就是 CN2 GIA，全程 `218.x/219.x` 走 9929，移动段走 CMIN2——三网精品回程稳了。

**2. backtrace —— 直接告诉你线路类型**

bash
curl -sL https://raw.githubusercontent.com/zhucaidan/mtr_trace/main/mtr_trace.sh | bash


这个脚本的好处是不用你自己看 AS 号判断，它直接在结果里标注"电信 CN2 GIA""联通 9929""移动 CMIN2"，新手友好。缺点是只能精确到 CN2 级别，CN2 GIA 和 CN2 GT 区分不够准，所以建议配合 BestTrace 一起看。

**3. mtr —— 持续监控丢包率**

bash
mtr -n -c 100 <目标IP>


mtr 是 ping 和 traceroute 的合体，对每一跳持续发包，统计丢包率和平均延迟。晚高峰时段跑一次 mtr，能精准定位是哪一跳在丢包——是商家机房出口、还是某段骨干、还是你的本地运营商。排查卡顿问题必备。

把这三个脚本用熟，任何香港 VPS 你买回来都能在半小时内判断出它的真实线路水平。嫌手动麻烦的，也可以用 adysec/script 这种聚合脚本，一次跑完基础信息、IO、全球测速、回程路由全套。
